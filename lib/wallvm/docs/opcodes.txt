opcodes.txt
Complete list of IR opcodes in the wallvm compiler.

== Integer Arithmetic ==
  add iN a, b        - Signed integer addition
  sub iN a, b        - Signed integer subtraction
  mul iN a, b        - Signed integer multiplication
  sdiv iN a, b       - Signed integer division
  udiv iN a, b       - Unsigned integer division
  srem iN a, b       - Signed integer remainder
  urem iN a, b       - Unsigned integer remainder
  and iN a, b        - Bitwise AND
  or iN a, b         - Bitwise OR
  xor iN a, b        - Bitwise XOR
  shl iN a, b        - Shift left (logical)
  ashr iN a, b       - Shift right (arithmetic, sign-extending)
  lshr iN a, b       - Shift right (logical, zero-extending)
  rotl iN a, b       - Rotate left
  rotr iN a, b       - Rotate right
  smin iN a, b       - Signed minimum
  smax iN a, b       - Signed maximum
  umin iN a, b       - Unsigned minimum
  umax iN a, b       - Unsigned maximum

== Integer Unary ==
  neg iN a           - Arithmetic negation (-a)
  not iN a           - Bitwise NOT (~a)
  abs iN a           - Absolute value
  ctpop iN a         - Population count (number of set bits)
  ctlz iN a          - Count leading zeros
  cttz iN a          - Count trailing zeros
  bswap iN a         - Byte swap (reverse endianness)

== Float Arithmetic ==
  fadd fN a, b       - Float addition
  fsub fN a, b       - Float subtraction
  fmul fN a, b       - Float multiplication
  fdiv fN a, b       - Float division
  fma fN a, b, c     - Fused multiply-add (a*b+c)

== Float Unary ==
  fabs fN a          - Float absolute value
  fsqrt fN a         - Float square root

== Memory ==
  load ty, ptr       - Load value of type ty from pointer
  store ty val, ptr  - Store value to pointer
  alloca ty          - Allocate stack space for type ty
  gep ty base, idx   - Get element pointer (base + idx * sizeof(ty))

== Comparison ==
  icmp pred iN a, b  - Integer comparison with predicate
  fcmp pred fN a, b  - Float comparison with predicate

  ICmp predicates: eq, ne, slt, sle, sgt, sge, ult, ule, ugt, uge
  FCmp predicates: oeq, one, olt, ole, ogt, oge, ueq, une, ult, ule, ugt, uge, uno, ord

== Control Flow ==
  br @block                     - Unconditional branch
  condbr cond, @true, @false    - Conditional branch
  ret ty val                    - Return value (ty may be void)
  call func, args...            - Call function with arguments

== Special ==
  select cond, a, b     - If cond then a else b
  unreachable           - Marks unreachable code
  noret                 - No-return marker (removed from output)

== Casts ==
  trunc iN a            - Truncate to narrower integer
  zext iN a             - Zero-extend to wider integer
  sext iN a             - Sign-extend to wider integer
  fptrunc fN a          - Truncate float to narrower float
  fpext fN a            - Extend float to wider float
  sitofp fN a           - Signed integer to float
  fptosi iN a           - Float to signed integer
  fptoui iN a           - Float to unsigned integer
  uitofp fN a           - Unsigned integer to float
  bitcast a             - Bitcast between same-width types

== Vector SIMD ==
  vec_add vN a, b       - Vector integer addition
  vec_sub vN a, b       - Vector integer subtraction
  vec_mul vN a, b       - Vector integer multiplication
  vec_div vN a, b       - Vector integer division
  vec_fadd vN a, b      - Vector float addition
  vec_fsub vN a, b      - Vector float subtraction
  vec_fmul vN a, b      - Vector float multiplication
  vec_fdiv vN a, b      - Vector float division
  vec_min vN a, b       - Vector element-wise minimum
  vec_max vN a, b       - Vector element-wise maximum
  vec_broadcast vN a    - Broadcast scalar to vector

== Atomic Operations ==
  atomic_load ty, ptr           - Atomic load with sequential consistency
  atomic_store ty val, ptr     - Atomic store with sequential consistency
  atomic_cmpxchg ty ptr, cmp, new - Atomic compare-and-exchange

== GC Operations ==
  gc_root ptr              - Register GC root for pointer
  gc_write_barrier ptr     - Insert write barrier for GC
  gc_safepoint             - Insert GC safepoint poll

== Inline Assembly ==
  inlineasm "template" "constraints" "clobbers", args...
    - Inline assembly with template string, constraint string,
      clobber list, and operand values.

== Phi ==
  phi ty [val1, @block1] [val2, @block2] ...
    - SSA phi function for control flow merge points

== Type System ==
  i8, i16, i32, i64    - Integer types (1-64 bits)
  f32, f64             - Floating point types (32/64 bits)
  void                 - No value
  ptr                  - Opaque pointer
  <N x type>           - Vector type (N elements of type)
  [N x type]           - Array type (N elements of type)
  func                 - Function type
