• E0305: Division by Zero in Constant Evaluation
	• Context: comptime (or const-initializer) code divides by a literal zero. clang -Wdivision-by-zero at runtime, hard error at comptime.
• E0306: Integer Literal Overflows Declared Type at Comptime
	• Context: `u8 x = 300;` — the literal fits no value of the declared type. rustc E0080 on const, clang -Wconstant-conversion.
• E0307: Constant Array Index Out of Bounds
	• Context: `arr[7]` on a fixed array of 4 under comptime/const evaluation. rustc E0080 "index out of bounds"; the error txt already wants this impossible for fixed arrays.
• E0603: Unreachable Code After Diverging Statement
	• Context: statements after `return`/`break`/`continue` in the same block never run. clang -Wunreachable-code, rustc unreachable_code (warn).
• E0604: Non-Void Function Reaches End Without Return
	• Context: a function with a non-void return type can fall off the end. go "missing return", clang -Wreturn-type (error here).
• E0606: Self-Assignment Has No Effect
	• Context: `x = x;` or `x += 0`-style no-ops the programmer almost never meant. clang -Wself-assign (warn).
• E0607: Use of Local Before All Paths Initialize It
	• Context: definite-assignment analysis: `i32 x; if c { x = 1; } return x;` — path without assignment. go "used before initialized", rustc E0381.
• E0608: Switch Not Exhaustive and Missing else
	• Context: a switch over an enum/variant lists some arms, no else, and no exhaustive coverage — per the wish at the top of this file: exhaustive, or else + fallthrough-warned.
• E0609: Unreachable Switch Case
	• Context: duplicate case value, or a variant already covered by an earlier arm. rustc unreachable_patterns (warn).
• E0610: Fallthrough Attribute on Last Arm
	• Context: `#[[fallthrough]]` on the final arm falls out of the switch; almost always a copy-paste vestige.
• E0801: Unused Variable
	• Context: binding never read. go refuses to compile ("declared and not used"), clang -Wunused-variable. coralc has --warn-unused; wire it here (warn).
• E0802: Unused Import
	• Context: import nobody references. rustc unused_imports, go "imported and not used" (warn).
• E0803: Unused Parameter
	• Context: parameter never read in the body. clang -Wunused-parameter, zig "unused function parameter" (warn, `_`/`_name` opts out).
• E0804: Binding Never Mutated but Declared Mutable
	• Context: rustc unused_mut; coralc's `const` bit set on decls (warn).
• E0805: Use of Deprecated Item
	• Context: item carries a deprecation attribute; message should name the replacement. rustc deprecated, clang -Wdeprecated-declarations (warn).
• E0806: Unknown Attribute Name
	• Context: `#[[inlne]]` — no such attribute; suggest nearest known by edit distance ("did you mean #[[inline]]?"). clang -Wunknown-attributes, rustc unknown attribute (warn).
• E0807: Duplicate Attribute on Same Item
	• Context: `#[[packed]] #[[packed]]` or two spellings of the same policy. clang -Wduplicate-attribute, rustc duplicate attributes (warn).
• E0901: Format String Argument Count Mismatch
	• Context: `println("{} {}", a)` — placeholders vs args. go vet printf, clang -Wformat-insufficient-args/-Wformat-extra-args. coral's println/format take `{}`-style strings. // i think this is supported or somthing, not sure, and the lsp doesn't show it
