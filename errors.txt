	• Context: A branch in a conditional or switch statement skips returning a value, while all other paths correctly yield a concrete hardware register return.
• E0602: Use of Partially Moved/Deallocated Stack Memory

• E0701: Ambiguous Statement Disambiguated as Variable Declaration
	• Context: The classic C++ Most Vexing Parse. The code Time Keeper(Timer()); could be a function call or a variable declaration. Your recursive descent parser uses tentative parsing, picks one, and warns the developer exactly how it resolved the ambiguity.
• E0702: Missing 'typename' or 'template' Keyword in Dependent Scope
