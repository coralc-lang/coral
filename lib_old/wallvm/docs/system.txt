system.txt
wallvm system architecture and module organization.

== Directory Structure ==

  ir_opcodes.crl          - All IR opcode definitions
  ir_types.crl            - IR type system, IrValue, IrInst, IrFunc, IrModule

  ir_metadata.crl         - IR metadata annotations
  ir_strings.crl          - String constant handling

  passes/                 - Optimization passes
    .passes.crl           - Pass module registry (36 imports)
    algebraic.crl         - Algebraic identity simplification
    borrowcheck.crl       - Borrow checker (diagnostic)
    branchprop.crl        - Branch propagation
    branch_factoring.crl  - Branch condition factoring
    branch_inversion.crl  - Branch inversion flattening
    cast_elim.crl         - Redundant type cast elimination
    cse.crl               - Common subexpression elimination
    constfold.crl         - Constant folding
    dce.crl               - Dead code elimination
    dse.crl               - Dead store elimination
    divmod.crl            - Division/modulo strength reduction
    gvn.crl               - Global value numbering
    idempotent.crl        - Idempotent op removal
    idiom.crl             - Idiom recognition
    inline.crl            - Function inlining
    involution.crl        - Involution chain collapse
    jump_thread.crl       - Jump-to-jump threading
    lex_canon.crl         - Lexicographic canonicalization
    licm.crl              - Loop invariant code motion
    loop_detect.crl       - Loop detection
    loopcse.crl           - Loop CSE
    lower_phis.crl        - Phi lowering
    macro_fusion.crl      - Macro-fusion preparation
    mem2reg.crl           - Memory to register promotion
    peephole.crl          - Peephole optimizer
    range.crl             - Range analysis
    sccp.crl              - Sparse conditional constant propagation
    select_to_branch.crl  - Select to branch conversion
    sroa.crl              - Return value optimization
    stack_layout.crl      - Stack layout optimization
    tco.crl               - Tail call optimization
    unroll.crl            - Loop unrolling
    validate.crl          - IR validation

  regalloc/               - Register allocation
    lsra.crl              - Linear scan register allocation

  gc/                     - Garbage collection

    x86_64/               - x86-64 targets

      x86_base.crl        - Shared emitter, codegen (cdecl/stdcall)

    wasm/                 - WebAssembly targets
      wasm.crl            - WASM text format backend

  std/                    - Standard library
    mman.crl              - Memory management (alloc/dealloc)

== Compilation Pipeline ==

1. Parse source → IR
2. Optimize IR (O0-O3 passes)
3. Register allocation (LSRA, optional graph coloring at O3)
4. Code generation (target-specific)
5. Emit assembly/object code

== Target Dispatch ==

The compiler selects targets based on calling convention and OS:
  - SystemV (Linux x86-64) → x86_64/linux
  - Win64 (Windows x86-64) → x86_64/windows
  - Cdecl/Stdcall (x86 32-bit) → x86/linux
  - Wasm32 → wasm

== IR Round-Trip ==

IR can be printed to text and parsed back:
  printer → ir_printer.crl (emitModule)
  parser → ir_parser.crl (parseModule)
  Supports all opcodes, metadata, inline asm, phi, GC ops

== Graph Register Allocator ==

Chaitin-Briggs style graph coloring allocator:
  - Builds interference graph from LSRA intervals
  - Simplify-select coloring with spill detection
  - Used at O3 for small leaf functions (≤8 blocks)
  - LSRA runs first, graph coloring refines
