passes.txt
This document describes all optimization passes in the wallvm compiler pipeline.

== Optimization Levels ==

-O0: validate, simplify, constfold, dce, validate
-O1: validate, abi_lower, comm_canon, simplify, constfold, involution, range, range_br_elim, branchprop, branch_inv_flat, cse, cast_elim, dse, jump_thread, idiom, peephole, dce, validate
-O2: validate, abi_lower, mem2reg, sroa, comm_canon, simplify, constfold, involution, range, range_br_elim, branchprop, sccp, adce, alias_analysis, memory_ssa, licm, gvn, loopcse, jump_thread, inl, cast_elim, idiom, peephole, dse, lowrphis, validate (iterative, max 5 iterations)
-O3: validate, abi_lower, mem2reg, sroa, stack_layout, comm_canon, lex_canon, simplify, constfold, involution, range, range_br_elim, branchprop, branch_inv_flat, branch_fact, divmod, sccp, adce, alias_analysis, memory_ssa, licm, gvn, loopcse, loop_interchange, loop_distribute, jump_thread, tail_dup, inl, tco, simd_vec, idiom, idempotent, cast_elim, macro_fusion, peephole, machine_opt, sel2br, dse, lowrphis, validate (iterative, max 8 iterations)

O2 is the standard optimization level: SSA construction, basic simplification,
standard loop opts (LICM, GVN, loop CSE), inlining, and peephole cleanup.
Fast, predictable compile times.

O3 adds aggressive transforms on top of O2:
  stack_layout, lex_canon, branch_inv_flat, branch_fact, divmod,
  loop_interchange, loop_distribute, tail_dup, tco, simd_vec,
  idempotent, macro_fusion, machine_opt, sel2br

Both O2 and O3 run alias analysis and memory SSA as pipeline phases before the
optimization passes, so consumers (dse, licm, gvn, simd_vec, machine_opt, loop_distribute)
share pre-built analysis results via the IrContext analysis cache.

== Pass Descriptions ==

-- validate (irPassValidate)
    Validates IR consistency: type correctness, block references, instruction well-formedness.

-- comm_canon (irPassCommCanonicalize)
    Canonicalizes commutative operations by sorting operands deterministically.
    Constants go to ops[1], otherwise sorted by value ID.
    Boosts CSE/GVN hit rates by making x+y and y+x look identical.

-- simplify (irPassSimplify)
    Algebraic identity simplification:
    - x+0=x, x*0=0, x*1=x, x/1=x, x%1=0
    - x&x=x, x|x=x, x^x=0, x-x=0
    - x*2^n = x<<n
    - select(true,x,y)=x, select(false,x,y)=y
    - select(x,x,y)=x, select(x,y,x)=y
    - not(not(x))=x, neg(neg(x))=x
    - sext(zext(x)) simplified, trunc(zext(x))=trunc(x)
    - fabs(fabs(x))=fabs(x), fabs(fneg(x))=fabs(x)

-- constfold (irPassConstfold)
    Constant folding for all arithmetic, comparison, and conversion operations.
    Handles: FMA 3-operand folding, ashr sign extension, SDiv/SRem INT64_MIN/-1,
    select with constant condition, unary float operations.

-- involution (irPassInvolution)
    Involution chain collapse - eliminates pairs of self-inverse operations:
    - not(not(x))=x, neg(neg(x))=x, fabs(fabs(x))=x
    - (x^C)^C=x, (x+C)+(-C)=x
    - trunc(zext(x))=trunc(x), zext(sext(x)) simplified
    - fptrunc(fpext(x))=x, bitcast(bitcast(x))=x

-- range (irPassRange)
    Range analysis using ICmp intervals. Merges AND/OR chains of comparisons
    on the same variable into optimized range checks.

-- range_br_elim (irPassRangeBranchElim)
    Branch elimination using range analysis. Folds CondBr instructions when
    the condition can be determined from dominating ICmp comparisons.

-- branchprop (irPassBranchProp)
    Branch propagation: folds constant conditions in CondBr instructions.

-- branch_inv_flat (irPassBranchInversionFlat)
    Redundant Branch Inversion Flattening: detects sequential conditional
    checks with overlapping/inverse predicates and replaces redundant
    CondBr with unconditional jumps. Also folds ICmp/FCmp with constant
    operands directly.

-- branch_fact (irPassBranchFactoring)
    Branch condition factoring: collapses inverted branch pairs (cond/!cond
    with same targets), factors common guard conditions from successor blocks.

-- divmod (irPassDivMod)
    Strength reduction for division and modulo operations.

-- gvn (irPassGvn)
    Global Value Numbering: eliminates redundant computations across basic
    blocks using value numbering. Uses alias analysis to handle loads —
    duplicate loads are eliminated when they must-alias the same address.
    Stores invalidate loads that may alias with them. Calls inline assembly
    invalidate all cached loads.

-- licm (irPassLicm)
    Loop Invariant Code Motion: hoists invariant instructions to loop preheaders.
    Enhanced with alias analysis: loads can be hoisted even from loops with stores,
    as long as no store in the loop may alias with the load's address. Calls and
    inline assembly are treated as potential aliasing stores.

-- loopcse (irPassLoopCse)
    Loop Common Subexpression Elimination.

-- sccp (irPassSccp)
    Sparse Conditional Constant Propagation: propagates constants and identifies
    unreachable blocks. Handles CondBr folding, SDiv/SRem edge cases.

-- jump_thread (irPassJumpThread)
    Jump-to-Jump threading: redirects unconditional branches through empty
    blocks to their targets. Folds CondBr with known constant condition.

-- tail_dup (irPassTailDup)
    Tail duplication: moves simple passthrough blocks into their predecessors,
    eliminating unconditional branches.

-- inl (irPassInline)
    Function inlining with cost model. Costs: arithmetic=1, memory=2, call=5,
    phi=3, conversion=1. Thresholds: O1=30, O2=60, O3=120.
    Caller growth limit: 4x. Max total inlined: 500 instructions.

-- tco (irPassAccumulate)
    Tail Call Optimization: converts tail calls to loops.

-- simd_vec (irPassAutoVectorize)
    SIMD auto-vectorization (O3 only). Detects:
    - ElemwiseLoadOpStore: vectorizes element-wise operations
    - BroadcastMul: broadcast scalar and multiply
    - ReductionSum/Min/Max: vector reduction operations
    - Dynamic vector width selection
    - Post-vectorization peephole cleanup
    Uses alias analysis to check that stores don't alias with loads,
    allowing vectorization of loops with writes to different arrays.

-- idiom (irPassIdiom)
    Idiom recognition: strength reduction patterns like
    multiply-rotate sequences, byte swaps, min/max selection.

-- idempotent (irPassIdempotent)
    Idempotent op removal / redundant write suppression:
    - Consecutive identical stores to same address
    - Redundant loads after store
    - Redundant bitcast chains
    - GEP with zero index
    - Dead alloca
    - Select with identical arms
    - ICMP with identical operands

-- dce (irPassDce)
    Dead Code Elimination: removes instructions with no users.
    Enhanced: removes unreachable blocks using reachability analysis.

-- adce (irPassAdce)
    Aggressive DCE: removes instructions not needed for side effects
    (stores, calls, terminators are always kept).

-- peephole (irPassPeephole)
    Peephole optimizer with 15+ patterns:
    - add/sub/mul identity (x+0, x-0, x*1)
    - and x,-1 = x; or x,0 = x
    - shift by 0
    - icmp eq x,x = true
    - select(true/false,...)
    - not(not(x)), neg(neg(x))
    - x^x=0, x-x=0
    - sext(zext(x)), trunc(zext(x))
    - br to single-br block redirection

-- mem2reg (irPassMem2Reg)
    Promotes allocas to SSA registers (phi nodes).

-- lowrphis (irLowerPhis)
    Lowers phi nodes to copies.

-- unroll (irPassUnroll)
    Loop unrolling. Opt-in via --funroll.

-- dse (irPassDse)
    Dead Store Elimination.

-- machine_opt (irMachineOpt)
    Machine-level CSE/DSE pass using MemorySSA. Uses alias analysis for
    precise memory optimization:
    - Store-to-load forwarding using MemorySSA dependency chains
    - Dead store elimination (store overwritten before read)
    - Cross-block store-to-load forwarding via dominance
    - Redundant load elimination via must-alias queries

-- loop_interchange (irPassLoopInterchange)
    Loop Interchange: swaps nested loop orders to improve data locality
    and enable vectorization. Safety checks ensure no loop-carried
    dependencies are violated. Improves cache performance for column-major
    array access patterns.

-- loop_distribute (irPassLoopDistribute)
    Loop Distribution: splits a loop body into multiple independent loops
    to enable vectorization. Useful when one part of the loop is vectorizable
    but another isn't, or when different parts access different arrays.

-- cast_elim (irPassCastElimination)
    Redundant Type Cast and Extension Elimination. Removes 10 patterns:
    - Cast to same type (bitcast identity)
    - Two identical casts in a row
    - trunc(zext(x)) where trunc brings back to original width
    - trunc(sext(x)) same pattern
    - zext(sext(x)) or sext(zext(x)) with matching widths
    - fpext(fptrunc(x)) or fptrunc(fpext(x)) with matching widths
    - sitofp(fptosi(x)) or fptosi(sitofp(x)) with matching widths
    - bitcast(bitcast(x)) -> bitcast(x)

-- lex_canon (irPassLexCanonicalize)
    Lexicographical Canonicalization of Commutative Trees. Flattens nested
    associative-commutative chains (add, mul, and, or, xor) and sorts
    operands by value ID for maximum CSE/GVN matching.

-- stack_layout (irPassStackLayout)
    Static Spatial Layout Sorting of Stack Variables. Counts access frequency
    of each alloca, sorts hot variables first, cold variables last in the
    entry block for L1 data cache optimization.

-- sroa (irPassSROA)
    Return Value Optimization. Forwards stored values directly to loads,
    eliminating alloca→store→load chains when safe.

== Structure Lane ==

    Runs after optimization, before register allocation:
    - Borrow checking (semantic, not optimization)
    - Loop unrolling (if enabled)
    - Dead store elimination

== Register Allocation ==

    Two allocators available:
    1. Linear Scan (LSRA): Fast, used by default
    2. Graph Coloring: Chaitin-Briggs style, refines LSRA results (O3, small leaf functions)

== IR System ==

    IR types: i8, i16, i32, i64, f32, f64, void, ptr, <N x type>, [N x type], func
    IR parser: Full round-trip support for all opcodes, metadata, inline asm
    IR printer: Full text format output with debug locations

== Backends ==

    x86_64 (bare-metal):
      - Full opcode coverage, leaf function optimization, variadic support
      - @PLT for external calls on Linux, AVX/AVX2/AVX-512/FMA support
      - LSRA + graph coloring register allocation

    x86_64 Linux (ELF):
      - SystemV ABI, .globl/.type/.size directives, full feature set

    x86_64 Windows:
      - Microsoft x64 ABI (rcx/rdx/r8/r9 args, shadow space, 32-byte alignment)

    x86 32-bit (cdecl/stdcall):
      - X86Emitter, cdecl/stdcall conventions, callee-save registers

    WebAssembly:
      - Stack machine, WASM text format output, no register allocation needed

== GC Runtime ==

    Tri-color mark-sweep with finalizer support in object header.
    Opcodes: GcRoot, GcWriteBarrier, GcSafepoint
